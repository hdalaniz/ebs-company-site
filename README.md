# Elevate Business Systems

Parent brand and product hub for Elevate Business Systems (EBS).

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

To connect Analyze / Insight CTAs to the existing EBS Insight app, copy `.env.example` to `.env.local` and set `NEXT_PUBLIC_EBS_INSIGHT_URL` to the real origin. Do not invent a production URL.
